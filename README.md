# 掌心星 PalmStar

让 BJD 娃娃成为 AstrBot 的“身体”：娃娃里的 ESP32 被触摸时上报事件，插件把它写成一句事件描述（如“（她轻轻摸了摸你的头）”），伪装成你发来的 QQ 私聊消息注入 AstrBot，bot 按人设、记忆和上下文正常回复到 QQ。

## 接口

```
GET http://服务器IP:8765/touch?part=head&token=你的token[&pressure=0-100]
```

| 状态码 | 含义 |
| --- | --- |
| 200 | 本地录音模式：已记下，返回 `"mode": "local"`，ESP32 播放本地录音；实时对话模式：已注入，返回 `"mode": "realtime"` 和事件 `id` |
| 400 | 部位未配置，或 pressure 不是 0-100 的整数 |
| 403 | token 不对 |
| 429 | 实时对话模式下该部位在冷却中，返回 `retry_after` 秒数 |
| 503 | 未配置 `target_qq`，或找不到 aiocqhttp 适配器 |

### 语音

```
POST http://服务器IP:8765/voice?token=你的token[&rate=16000]
Body: 16 位小端单声道 PCM 原始数据
```

插件把音频交给 AstrBot 的语音识别服务转成文字，套进“语音消息模板”后注入 QQ。返回 `{"ok": true, "text": "注入的内容"}`；422 表示没识别出文字，502 表示识别服务调用失败，503 表示没找到识别服务。

### 语音回复

```
GET http://服务器IP:8765/speech?id=事件ID&seq=句子序号&token=你的token[&wait=60]
```

`/touch` 和 `/voice` 成功时会返回事件 `id`。沈星回的回复一生成（发到 QQ 之前），插件就开始合成语音：默认整段一次合成，开启“逐句合成语音”后按分段一句一句合成。分段规则沿用 AstrBot 的分段回复设置，自定义分隔符（如 `$`）不会被读出来。ESP32 依次请求 `seq=0、1、2…`，每次拿到一段 24kHz 16 位单声道 PCM（200），响应头 `X-Last: 1` 表示最后一段；没有更多内容（没回复、没配语音合成、超时）返回 204。服务器需要安装 ffmpeg。

## 配置

在 WebUI 的插件配置里填写：

- **HTTP 监听端口**：默认 8765。Windows 防火墙需要放行该端口。
- **校验 token**：ESP32 请求里带上相同的值。
- **你的 QQ 号**：必填。
- **触摸实时对话**：默认关闭。关闭时触摸只播放娃娃本地录音，触摸记录在你下一次发消息、按住手心说话或触发主动消息时一起带给 bot；开启后触摸立即让 bot 回复并说出来。
- **部位 → 事件描述**：每行 `部位=描述`，新增部位只需加一行。
- **同部位冷却时间**、**压力值附加描述**：见配置说明。
- **语音识别服务 ID**：AstrBot「服务提供商」里语音转文字服务的 ID，例如云端 Whisper 接口。
- **语音消息模板**：识别出的文字填进 `{text}`。
- **语音合成服务 ID**：AstrBot「服务提供商」里文字转语音服务的 ID。不需要开启全局语音输出，QQ 里仍是文字。
- **朗读时跳过括号内容**：（笑）、*动作* 这类内容不读出来。
- **逐句合成语音**：默认关闭，整段回复一次合成，语调更连贯；开启后第一句好了就开始播放。
- **娃娃消息跳过的插件**：默认跳过消息防抖插件，触摸和语音后立即回复。你自己发的消息仍正常防抖。

## 注意

- 仅支持 aiocqhttp(OneBot v11) 适配器的私聊。
- 请关闭 AstrBot 的“回复时引用消息”（`reply_with_quote`）。注入的消息在 QQ 里并不存在，引用它会导致发送失败。
